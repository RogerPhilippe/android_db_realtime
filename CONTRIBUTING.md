# Contributing to SQLiteRealtime (Android)

Thank you for your interest in contributing! Please read the following before
opening a Pull Request.

## How to contribute

1. Open an Issue describing the bug or the proposed feature, so we can align
   before you start coding (this avoids rework).
2. Fork the repository and create a branch from `main`.
3. Follow the code style already used in the project.
4. Test your changes locally before opening the PR.
5. Clearly describe in the PR description what was changed and why.
